## Findings
- The niceness is set by the child itself as an absolute value (`os.setpriority`, never below the current one): a
  `nice -n 19` prefix is an increment and gives 20 on macOS when the UI is already niced.
- Stop sends SIGTERM to the job's process group, SIGKILL after 5 s; the request returns once the state is final.
- Outside the listed defects: the running card was rebuilt on every 1.5 s poll, which would take keyboard focus
  off the Stop button; a poll now only refreshes the log text.
- Not checked: stopping a real backtest in the middle of a DuckDB write (the tests and the browser check use a
  sleeping stand-in; a real `cash` backtest ends too fast to stop).
- `ruff check src/cs2trader/ui` reports 3 errors that predate this task (`plain.py:416`, `settings_api.py:117`,
  `server.py:130`); left alone.
